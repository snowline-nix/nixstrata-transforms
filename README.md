# nixstrata-transforms

Reusable transform functions for `nixstrata`.

This is just a collection of small transforms for building pipelines for types.

It includes things like:

* value object creation
* type checking
* priority handling
* merging values
* common error handling
* helpers for composing transforms

Basically, `nixstrata-transforms` provides some common transform steps so they don't have to be implemented over and over again.
